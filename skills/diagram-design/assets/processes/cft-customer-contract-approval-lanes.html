Как читать схему

  • Прямоугольник - действие сотрудника; дорожка называет владельца.
  • XOR с X - исключающий выбор после задачи или бизнес-правила; подпись стоит непосредственно у потока.
  • AND с + - параллельный запуск или ожидание всех трёх решений.
  • Пунктирный поток - сообщение внешнему black-box пулу «Клиент».
  • R1-R5 - парные возвраты к одному входу полного внутреннего раунда.
  • Овал - успешное завершение или отдельная техническая остановка.
  • Свернутая техническая остановка - единственный presentation-only fallback к терминалу; это не решение сотрудника и не бизнес-переход.

Текстовое описание маршрута

  2. Автоматически; Приём. Автоматически определить входной сценарий. Результат: Выбран один из двух сценариев. Исходы: Только ТКП; ТКП + договор клиента.
  3. Юрист; Подготовка пакета. Подготовить договор по ТКП; загрузить обязательный файл. Результат: Первый договор и его объект в хранилище.
  4. Автоматически; Внутренний раунд. Запустить один блокирующий параллельный раунд. Результат: Три задания созданы одновременно.
  5. Главный инженер; Внутренний раунд. Принять решение по договору. Результат: Решение главного инженера. Исходы: Согласовано; Есть замечания.
  6. Главный бухгалтер; Внутренний раунд. Принять решение по договору. Результат: Решение главного бухгалтера. Исходы: Согласовано; Есть замечания.
  7. Руководитель; Внутренний раунд. Принять решение по договору. Результат: Решение руководителя. Исходы: Согласовано; Есть замечания.
  8. Автоматически; Разбор результата. Все 3 участника согласовали?. Результат: Полный раунд завершён. Исходы: Все три участника согласовали; Хотя бы у одного участника есть замечания.
  9. Автоматически; Разбор результата. Автоматически выбрать фактический вид юридической доработки. Результат: Выбрано одно взаимоисключающее задание. Исходы: Только ТКП и протокола ещё нет; Только ТКП и протокол уже есть; Договор клиента и протокола ещё нет; Договор клиента и протокол уже есть.
